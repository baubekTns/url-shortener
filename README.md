# URL Shortener

A production-inspired URL shortening service built with Java and Spring Boot.

## Planned Features

- URL shortening
- Fast HTTP redirects
- Redis caching
- PostgreSQL persistence
- Custom aliases
- URL expiration
- JWT authentication
- Analytics dashboard
- Docker deployment

## Tech Stack

- Java 21
- Spring Boot
- PostgreSQL
- Redis
- Docker
- React (planned)
